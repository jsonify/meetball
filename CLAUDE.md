# Working on Meetball

## Pull requests

- Always open a pull request for finished work; don't wait to be asked.
- Then merge it yourself, without waiting for the owner to look: once CI is green on the latest commit and the PR
  has no merge conflicts, merge it. If CI fails, fix it and merge once it's green; never merge red or conflicted.
- Follow-up work after a merge goes on a fresh branch from `main` and gets its own PR.
